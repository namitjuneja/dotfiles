# Hyprland Config — Setup Notes

This documents all customizations made to the default Hyprland config
(`https://github.com/hyprwm/Hyprland/blob/main/example/hyprland.conf`),
plus every package installed during setup. Use this to restore the setup
from scratch.

---

## Packages to Install

### pacman (official repos)

```bash
sudo pacman -S --needed \
  rofi-wayland \
  hyprpolkitagent \
  nwg-displays \
  waybar \
  blueman \
  hyprshot \
  swaync \
  hyprlock \
  hyprpaper \
  swww \
  cliphist \
  wl-clipboard \
  pavucontrol \
  playerctl \
  brightnessctl \
  base-devel \
  git \
  xorg-xwayland \
  hyprsunset \
  pipewire \
  pipewire-pulse \
  wireplumber \
  xdg-desktop-portal-hyprland \
  loupe
```

> `pipewire-pulse` is a drop-in PulseAudio replacement (keeps `pavucontrol` working). `xdg-desktop-portal-hyprland` is required for screensharing. All four start automatically via systemd user services — no `exec-once` needed.

> `blueman` also needs bluetooth enabled:
> ```bash
> sudo systemctl enable --now bluetooth
> ```

### yay (AUR helper — install first)

```bash
git clone https://aur.archlinux.org/yay-bin.git
cd yay-bin
makepkg -si
```

### AUR packages (via yay)

```bash
yay -S rofi-bluetooth-git
```

> `rofi-bluetooth` was also attempted but `rofi-bluetooth-git` is the AUR package that worked.

## Changes from Default hyprland.conf

### Monitors

**Default:**
```
monitor=,preferred,auto,auto
```

**Custom:**
```
monitor=,preferred,auto,2
monitor=HDMI-A-2,3440x1440@29.99,0x0,1.6
```

- Added explicit ultrawide monitor: `HDMI-A-2` at 3440x1440, 60Hz, scale 1.6
- Default/fallback monitor uses scale factor `2` instead of `auto`
- `monitors.conf` is generated by `nwg-displays` and can be used to manage
  monitor layout via GUI. The `hyprland.conf` entry takes precedence if not
  sourced separately.

> **Jankiness root cause (resolved):** The monitor was initially running at `@29.99` (~30fps),
> which caused the cursor and all animations to look choppy and laggy. Switching to `@59.98`
> (60fps) fixed it entirely. If everything feels janky, check the refresh rate first.
>
> **Other methods not yet tried (if jankiness returns):**
> - Remove fractional scaling (set scale to `1.0`) — fractional scaling can cause rendering
>   artifacts and performance issues on some setups.

### Autostart

**Default:** all commented out  
**Custom:**
```
exec-once = hyprpaper &
exec-once = waybar &
exec-once = swaync &
exec-once = hyprsunset --temperature 5000 &
exec-once = wl-paste --type text --watch cliphist store # Stores text data
exec-once = wl-paste --type image --watch cliphist store # Stores only image data
```

- `hyprpaper` — wallpaper daemon
- `waybar` — status bar
- `swaync` — notification daemon (SwayNotificationCenter)
- `hyprsunset --temperature 5000` — blue light filter at 5000K color temperature
- `cliphist` — clipboard manager; `wl-paste --watch` feeds clipboard events into its store

### Look and Feel

#### general — gaps

**Default:** `gaps_out = 20`  
**Custom:** `gaps_out = 5`

Reduced outer gaps from 20 to 5 to keep a tighter layout.

---

#### decoration

**Default:**
```
rounding = 10
active_opacity = 1.0
inactive_opacity = 1.0
blur { size = 3; passes = 1; vibrancy = 0.1696 }
```

**Custom:**
```
dim_special = 0.8          # dims special/scratchpad workspace overlay

rounding = 0               # removed rounded corners entirely
rounding_power = 2

active_opacity = 0.92      # slight transparency for focused windows
inactive_opacity = 0.82    # more transparency for unfocused windows

blur {
    enabled = true
    size = 12              # much heavier blur
    passes = 4
    new_optimizations = true
    xray = false
    vibrancy = 0.8
    vibrancy_darkness = 0.5
    brightness = 1.1
    contrast = 0.9
    noise = 0.02
    popups = true          # blur popups too
}
```

Heavy blur with transparency on all windows. No rounded corners.

> **Firefox exception:** A windowrule forces `opacity = 1 override 1 override` for Firefox,
> exempting it from the global active/inactive opacity so it renders fully opaque.

> **Obsidian exception:** Same as Firefox — a windowrule forces `opacity = 1 override 1 override`
> for Obsidian so it renders fully opaque.

> **Performance workaround (active):** Blur and shadow are currently disabled to reduce GPU load:
> ```
> decoration {
>     blur { enabled = false }
>     shadow { enabled = false }
> }
> ```
> To restore, set both back to `enabled = true` and re-enable the blur settings above.

---

#### animations — workspace transitions disabled

**Default:** workspace animations enabled with `fade` style  
**Custom:** workspace animations disabled (set to `0`):
```
animation = workspaces,    0, ...
animation = workspacesIn,  0, ...
animation = workspacesOut, 0, ...
```

Workspace switching is instant. All other animations (windows, borders,
layers, fade) remain enabled.

---

#### Named persistent workspaces (1–9)

Workspaces 1–9 are named and marked `persistent:true` so they always exist,
even when empty. This lets Waybar's `hyprland/workspaces` module see real
workspace state (window counts, urgent flags) and apply CSS classes like
`button.empty` and `button.urgent` correctly.

```
workspace = 1, name:1: Firefox, persistent:true
...
workspace = 9, name:9: Music, persistent:true
```

> **Note:** Use Hyprland's `persistent:true` rather than Waybar's
> `persistent-workspaces` — Waybar's approach creates hollow stubs that
> don't carry real workspace state, so CSS classes won't work.

---

#### Smart gaps (no gaps when only one window)

**Default:** commented out  
**Custom:** enabled:
```
workspace = w[tv1], gapsout:0, gapsin:0
workspace = f[1], gapsout:0, gapsin:0
```
Plus matching `windowrule` blocks to remove borders/rounding in those cases.

---

#### misc

**Default:** `force_default_wallpaper = -1`, `disable_hyprland_logo = false`  
**Custom:** `force_default_wallpaper = 0`, `disable_hyprland_logo = true`

Disables the default anime mascot wallpaper and the Hyprland logo on startup.

Also added `vfr = true` (variable frame rate) to reduce idle GPU usage.

### Input

#### Keyboard options

**Default:** `kb_options =` (empty)  
**Custom:** `kb_options = altwin:swap_alt_win,caps:escape`

- `altwin:swap_alt_win` — swaps the Alt and Win (Super) keys at the kernel level
- `caps:escape` — Caps Lock acts as Escape

#### Mouse sensitivity

**Default:** `sensitivity = 0`  
**Custom:** `sensitivity = 1`

#### Hardware cursors disabled

**Default:** not set  
**Custom:**
```
cursor {
    no_hardware_cursors = true
}
```

Fixes cursor rendering issues (common with NVIDIA or when using Wayland compositors).

#### Workspace switching — remapped to bare F-keys

**Default:** `Super + 1–9` to switch workspaces  
**Custom:** bare `F1–F9` (no modifier) to switch workspaces

```
bind = , F1, workspace, 1
...
bind = , F9, workspace, 9
```

Move window to workspace: `Shift + F1–F9` using `movetoworkspacesilent`
(window moves silently without switching to that workspace — default used
`movetoworkspace` which also switches focus).

## Additional Config Files

### hyprpaper.conf

Wallpaper set to a photo from Downloads. Uses `fit_mode = cover` on HDMI-A-2.
Update the path if the wallpaper file moves:

```
preload = /home/namit/Downloads/loren-gu-IG1EdbuYCy8-unsplash.jpg

wallpaper {
    monitor = HDMI-A-2
    path = /home/namit/Downloads/loren-gu-IG1EdbuYCy8-unsplash.jpg
    fit_mode = cover
}

splash = false
ipc = off
```

### hyprlock.conf

Custom lock screen with:
- Blurred screenshot as background (4 passes, brightness 0.6)
- Large clock label using `MesloLGS Nerd Font`
- Date label (updates every 60s)
- Styled input field with cyan/green gradient matching the Hyprland border colors
- Status bar at bottom showing time, battery %, and volume %
- Glow ring + card shapes for decoration

Font used: **MesloLGS Nerd Font** — install if missing:
```bash
yay -S ttf-meslo-nerd
```

### monitors.conf

Auto-generated by `nwg-displays`. Run `nwg-displays` to configure monitor
layout via GUI and it will update this file. Currently:

```
monitor=HDMI-A-2,3440x1440@59.98,0x0,1.0
```

> Note: The monitor line in `hyprland.conf` sets scale 1.6 at 29.99Hz.
> `monitors.conf` sets 59.98Hz at scale 1.0. These may conflict — the one
> that takes effect depends on which is loaded last or whether `monitors.conf`
> is sourced via `source =` in `hyprland.conf`. Review if display scaling
> looks wrong after reinstall.
